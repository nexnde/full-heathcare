STEP 1: Open Terminal
  → Windows: Press WIN+R, type "cmd", press Enter

STEP 2: Navigate to Project
  → Paste: cd "c:\Users\Rohit\OneDrive\Desktop\Meditrace\medtrace"
  → Press: Enter

STEP 3: Copy 5 React Files to src/ folder
  Files to copy:
    • AppNestly.js
    • AppNestly.css
    • OnboardingNestly.js
    • HomeNestly.js
    • BrowseNestly.js
  
  How:
    1. Open File Explorer
    2. Go to: c:\Users\Rohit\OneDrive\Desktop\Meditrace\medtrace
    3. Select the 5 files above
    4. Right-click → Copy
    5. Go to: c:\Users\Rohit\OneDrive\Desktop\Meditrace\medtrace\src
    6. Right-click → Paste

STEP 4: Create 8 Components from COMPONENT_TEMPLATES.js
  Open the file "COMPONENT_TEMPLATES.js"
  For each template, create a new .js file in src/ folder:
    1. MessagesNestly.js (copy MessagesTemplate)

  Wait for it to finish

STEP 7: Start the App

  Wait for: "Compiled successfully!"

  Go to: http://localhost:3000

================================================================================
                            QUICK HELP
================================================================================

Terminal won't open?
  → Use Task Manager to open Command Prompt
  → Or use Windows Search to find "cmd"

npm command not found?
  → Download and install Node.js from nodejs.org
  → Restart Terminal after install

Port 3000 already in use?
  → Use: npm start -- --port 3001

Blank page in browser?
  → Press F12 to check for errors
  → Try refreshing the page (F5)

Files won't copy?
  → Make sure you're in the right folders
  → Check for file name typos
